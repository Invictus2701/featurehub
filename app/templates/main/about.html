À propos de FeatureHub

FeatureHub est une application web développée dans le cadre du cours d'Architecture Web. Elle permet aux équipes de collecter, gérer et prioriser les demandes de fonctionnalités, les signalements de bugs et les tâches de maintenance au sein d'un projet logiciel.

Objectif

L'objectif principal est de fournir un espace centralisé où chaque membre d'une équipe peut soumettre une idée, signaler un dysfonctionnement ou proposer une amélioration, tout en offrant une vue d'ensemble claire grâce à des filtres, des tris et des indicateurs visuels.

Technologies utilisées

  • Python 3 & Flask — framework web léger côté serveur.
  • SQLite via SQLAlchemy — base de données relationnelle embarquée et son ORM.
  • Jinja2 — moteur de templates pour le rendu HTML dynamique.
  • Bootstrap 5 & Bootstrap Icons — framework CSS pour une interface responsive et moderne.
  • Flask-Login — gestion de l'authentification et des sessions web (cookies signés).
  • Flask-JWT-Extended — protection de l'API REST par tokens JWT (Bearer).
  • Werkzeug — utilitaires de sécurité : hachage des mots de passe et nettoyage des noms de fichiers uploadés.

Architecture

L'application suit le pattern MVC (Model-View-Controller) et est organisée en Application Factory avec trois Blueprints : main (interface web), auth (inscription/connexion) et api (API REST versionnée sous /api/v1/).
