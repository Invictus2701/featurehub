À propos de FeatureHub

FeatureHub est une application web qui permet aux équipes de collecter, gérer et prioriser les demandes de fonctionnalités, les bugs et les tâches de maintenance.

Mission

Centraliser les demandes pour ne plus rien perdre, et faciliter la priorisation grâce à des indicateurs visuels clairs (statut, nature, priorité).

Technologies utilisées

  • Flask — un micro-framework Python qui gère le côté serveur.
  • Jinja2 — un moteur de templates qui transforme nos modèles HTML en vraies pages.
  • Bootstrap 5 — un framework CSS qui donne tout de suite un look propre et responsive.

Contexte

Projet réalisé dans le cadre du cours d'Architecture Web à l'ECAM.
